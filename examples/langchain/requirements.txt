# The Python desk's dependencies. Install from THIS directory, because the path
# below is relative to wherever pip is run:
#
#     python3 -m venv .venv
#     .venv/bin/pip install -r requirements.txt
#
# `run.sh` does the same thing by hand, into a venv under its scratch directory,
# so nothing runtime lands in the checkout. Point SALVOR_EXAMPLE_PYTHON at an
# interpreter that already has these and it skips the install entirely.

# langchain-core. It is a path rather than a version range because the extra is
# in the next release of `salvor` and is not on PyPI yet; once it ships, this
# line becomes `salvor[langchain]` and nothing else here changes.
-e ../../sdks/python[langchain]
