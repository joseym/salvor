Salvor client-driven run

This page owns an agent loop and streams the events it produces to a Salvor control plane, which owns the durable log. It opens a run, appends its own control events, re-opens the run and replays it from the fetched log (zero live calls), then drives a streaming model step whose tokens paint into the ticker below. See README.md for the offline bring-up and the CORS note.
