# Code of Conduct

This project follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct). It applies in issues, pull requests, discussions, and commit messages.

The short version: treat people with respect, patience, and kindness. Assume the person on the other side of the thread is trying. Criticize code and designs as much as you like, and do not extend that to the people who wrote them.

To report a problem, email me@joseymorton.com. Reports go to the maintainer, are handled privately, and the reporter's identity is not shared without their agreement. Since this is a single-maintainer project, a report about the maintainer has nowhere internal to escalate; the Rust community team can be reached at conduct@rust-lang.org for anything involving Rust community spaces.
