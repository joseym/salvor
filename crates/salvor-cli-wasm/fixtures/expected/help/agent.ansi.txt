Author-time agent definition tools: print the content hash a graph `agent` node has to reference. Reads no store and drives no run

[1m[4mUsage:[0m [1msalvor agent[0m [OPTIONS] <COMMAND>

[1m[4mCommands:[0m
  [1mhash[0m      Print an agent definition's content hash, the `sha256:<64 hex>` string a graph `agent` node references
  [1mvalidate[0m  Build an agent definition and report what it declares, or the precise field-level error that stops it from building
  [1mhelp[0m      Print this message or the help of the given subcommand(s)

[1m[4mOptions:[0m
      [1m--store[0m <PATH>
          Path to the SQLite event store.
          
          The precedence is flag, then the `SALVOR_STORE` environment variable, then the default: an explicit `--store` wins, else `SALVOR_STORE`, else `./salvor.db`.
          
          [env: SALVOR_STORE=]
          [default: ./salvor.db]

  [1m-h[0m, [1m--help[0m
          Print help (see a summary with '-h')
