Salvor CLI: run, resume, list, history, and replay for durable agent runs

Usage: salvor [OPTIONS] <COMMAND>

Commands:
  run          Start a fresh run of an agent
  resume       Continue an existing run: resume a parked one, or recover a crashed one
  fork         Fork a graph run from a node boundary into a NEW run, refusing to re-execute a recorded write the operator has not acknowledged
  resolve      Record the completion of a dangling write by hand, after verifying it
  abandon      Abandon a run: retire it by hand without finishing or failing it, for a run that is dead forever or no longer worth carrying
  list         List runs in the store, newest activity last. Filters narrow what is printed; with none, every run is listed
  completions  Print a shell completion script for `salvor` on stdout
  history      Print a run's event log
  replay       Re-derive a run's state from its log without executing anything
  serve        Run the control-plane HTTP + server-sent-events server over the store
  build        Build the whole product from a salvor checkout: the web dashboard, then the release binary that embeds it
  graph        Author-time graph document tools: validate a document, or print its JSON Schema. These read no store and drive no run
  help         Print this message or the help of the given subcommand(s)

Options:
      --store <PATH>
          Path to the SQLite event store.
          
          The precedence is flag, then the `SALVOR_STORE` environment variable, then the default: an explicit `--store` wins, else `SALVOR_STORE`, else `./salvor.db`.
          
          [env: SALVOR_STORE=]
          [default: ./salvor.db]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
