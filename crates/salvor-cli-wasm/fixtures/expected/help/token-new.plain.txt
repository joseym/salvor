Add a named bearer token to a token file: mint one from the OS CSPRNG (or read one from stdin with `--stdin`), print it once, and append its SHA-256 under `[tokens.<name>]`

Usage: salvor token new [OPTIONS] --file <FILE> <NAME>

Arguments:
  <NAME>
          The name to add: `[a-z0-9-]`, 1 to 64 characters. This is the name an auth-failure or auth-success log line carries; it is never the token itself

Options:
      --file <FILE>
          The token file to append to (the same file `--token-file` names). Refused unless it is mode 0600 or tighter and owned by the user running this command, the same rules `salvor serve --token-file` checks on every read

      --create
          Create `--file` at mode 0600 if it does not already exist, rather than refusing on a missing file

      --stdin
          Read the token from stdin instead of minting one, for importing a token minted elsewhere (a value another tool generated, or one moved from another token file). Held to the same 16-byte floor `--auth-token` checks, and to printable ASCII with no space, which is what an `Authorization` header can carry; trailing newline is trimmed

  -h, --help
          Print help (see a summary with '-h')
