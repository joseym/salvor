About this canvas

What this is, and how the canvas works.

This canvas is where you author a graph and fork a run — the two things a timeline cannot do. It shows the topology, not the record: to read a run you still use the Inspector, where the log folds event by event. A static picture cannot honestly show a data-dependent branch, so this view will never try to replace it.

The projection is a summary; the log is the record. In Run mode every node is coloured from the server's own projection of the run's one append-only log (GET /v1/runs/{id}/graph) — the same log the Inspector folds, no second copy. The inked route is the case the run recorded at the branch, never a guess, and the road not taken reads as skipped, not as absent.

Where a node sits is presentation, not part of the graph. The hash is taken over the nodes and edges only; the drawing is derived from them. So a node's position can never change a graph's identity, and editing a published graph is impossible the same way: a changed byte is a different hash, which is a different graph.

A fork cannot edit the graph. It reuses the origin's hash — a run of a different graph would not be a fork of this one. What a fork does change is what has already happened in the world: every write the origin recorded downstream of the fork point will run a second time. The hazard review lists each one and refuses to proceed until you have acknowledged it — and then writes your acknowledgement into the new run's log, permanently.

"Forks of this run" is derived. The parent recorded nothing. A forked run carries its origin in its own log; the parent's log is append-only and was closed before its children existed, so it can never point forward at them. The server indexes every run's ForkedFrom and answers the reverse question (GET /v1/runs/{id}/forks) as a projection, labelled derived on its face rather than passing for memory.

This dashboard is reading {{ serverMetaText() }}, from the same GET /v1/capabilities probe the honesty chip above reads. A dash means the probe has not resolved yet, or the server predates this field.
